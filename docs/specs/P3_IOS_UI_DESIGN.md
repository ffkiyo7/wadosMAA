# S3-1：iOS 27 UI 细化设计

> 状态：**已确认定稿（2026-11-24）**。A1–A4 已按建议接受。
> 依据：总 Spec §6、Claude Artifact「Wado's MAA iOS 设计稿」E1–E31、`feat/decouple-ios` 的 iOS 实现。
> 三者不一致时，本文 §7 列出差异和建议；未拍板前不改界面。

---

## 1. 设计原则

1. **手机是遥控器**：3 秒看清 Mac mini 在干什么，1 步开跑或叫停。
2. **E 七段视觉**：借健康 App 的版式节奏，主图形是日常七段图和活动关卡圆环。
3. **信息自解释**：布局和状态能说明的，不再加说明文字。
4. **原生优先**：Liquid Glass Tab Bar、`NavigationStack`、Sheet、系统确认框、`List` / `Form`。
5. **不移植 Mac 界面**：只沿用 4 Tab 概念和后端数据语义。
6. **能力边界**：不提供碎石、吃非临期药、借助战、忽略练度等降级入口，也不录入森空岛 token。

## 2. 全局外壳

```text
TabView
├── 今天
├── 抄作业（角标 = 当期未通关数）
├── 日常
└── 设置

全局层
├── Tab Bar 底部配件：运行中显示胶囊；空闲且在「今天」显示「现在开一场」
├── 连接异常横幅：固定在各 Tab 内容顶部
├── Toast：操作结果与撤销
└── Sheet：实时进度 / 现在开一场 / 配对
```

### 2.1 运行胶囊（E3、E9、E12、E13）

- 任一 Tab 只要有运行就显示：日常用七段图，抄作业用圆环，其他任务转圈。
- 点主体打开实时进度 Sheet；可停止时右侧有 44pt 停止键。
- 停止键先打开进度 Sheet，再弹确认；请求带当前 `run_id`。

### 2.2 连接异常（E16）

| 状态 | 横幅 | 操作 |
|---|---|---|
| 离线 | Mac mini 离线 | 重试 |
| Token 失效 | Token 失效 | 重新配对 |
| 证书不匹配 | 证书不匹配 | 查看连接详情 |
| 隧道不通 | 隧道不通 | 重试 |
| 在线但局域网证书异常 | 局域网证书不匹配 | 查看连接详情 |

非在线时保留旧数据并显示数据时间，所有写操作禁用。

### 2.3 Deep Link

| 链接 | 去向 |
|---|---|
| `wadosmaa://run/latest` | 运行中打开进度，否则打开最近一场详情 |

## 3. 四个 Tab

### 3.1 今天（E1–E4、E14、E15、E23–E25）

顶部横滑切换：**概览 / 当前场 / 理智**；抄作业芯片直接跳到抄作业 Tab。

```text
[游戏资源提示条：仅 blocked / stale / running]
[概览] [晚场 22:00] [理智 11/208] [抄作业 差 7 关]

今晚还有一场
┌ 当前场卡：时间、关卡、七段图 ┐
│ 换关 · 刷理智 · 跳过         │
└──────────────────────────────┘
[另一场：结果或计划]
[当期活动：剩余时间与三类进度]
[最近：3 条 → 历史记录]
                 底部：现在开一场
```

- **场次状态**：待跑、运行中、已完成、未完成、已跳过、已关闭。
- **可编辑范围**：只有待跑和已跳过可改；已跳过只保留「恢复」。已开跑后只读。
- **当前场页**：待跑显示定关来源、目标、理智、环节数；运行中显示七段、当前步骤、ETA、时间线、把数、掉落和理智。
- **理智页**：实测值用实心，估算增长用虚线。
- **资源提示**：`blocked`、`stale` 可点「现在更新」，`running` 只显示进度。

**现在开一场**：选关（前 4 个快捷项 + 全部关卡）→ 6 个临时环节 → 开始 → 系统确认。被占用时主按钮显示占用原因并禁用；保护窗口内先走强开确认。

**历史与详情**：历史支持全部 / 日常 / 抄作业筛选、按日期分组和分页。详情含战报摘要、恢复备注、截图（全屏双指缩放）和尾部 200 行日志。

### 3.2 抄作业（E5、E6、E10、E21、E26–E28）

```text
活动名                         规则
[三层圆环]  [普通 9/12] [EX 6/8] [S 2/4]
还差 7 关                      剩 6 小时
自动抄作业                        [开关]
未通关卡列表
已通 N（折叠）
```

| 后端状态 | 界面 | 可进入预览 |
|---|---|---|
| `todo` | 待抄 | 是 |
| `scheduled` | 排程中 | 是 |
| `raid_pending` | 突袭待补 | 是 |
| `gap` | 练度不足 | 是 |
| `daily_cap` | 今日已达上限 | 是 |
| `locked` | 未解锁 | 是 |
| `no_nav` / `not_indexed` | 无导航 | 否 |
| `cleared` | 已通（折叠） | 否 |

- 未通行左滑「我打过了」；有本地记录的已通格可「撤销通关记录」。
- 预览携带 UUID `request_id`，取消或离开页面立即调用 `DELETE`。
- 自动选中最优完美作业；练度不足项标红、不可选，可展开查看缺口。
- 确认开打后回到实时进度。
- 规则 Sheet 只放 4 个阈值，0 次表示不限。

### 3.3 日常（E7、E22、E29）

从上到下：早晚场时间与开关 → 保护窗口 → 默认关卡 → 5 个默认环节 → 临期药 → 公招 → 剿灭预留 → 掉落上报 → 领奖 → 信用商店。

- 右上角显示最近修改来源和时间，如 `iOS 21:48`。
- 配置即时生效，可撤销的改动用 Toast 提供「撤销」。
- 信用商店支持优先买 / 不买列表的增删和排序。

### 3.4 设置（E8、E11、E30）

- 连接卡：链路、实测 RTT、测试连接。
- 入口：扫码配对、推送、游戏资源、调度器、iOS 签名、高级。
- 调度器和 iOS 签名当前只读；高级是 Phase 4 占位。
- 配对：未配对 → 扫码或手工填写 → 测试连接 → 保存到钥匙串。
- 连接详情：「编辑」打开预填当前配置的表单，可单独改 Token 或补备用指纹。

## 4. 状态规范（E17、E24、E27、E28）

| 场景 | 处理 |
|---|---|
| 首次加载 | 骨架屏，尊重「减弱动态效果」 |
| 空态 | `ContentUnavailableView`，如无活动、无记录、无日志 |
| 弱网 / 离线 | 保留旧数据和时间，禁用写操作 |
| 跨轨切换 | 由连接状态机重连，不清空已有数据 |
| 操作进行中 | 按钮内转圈并防重复提交 |
| 被占用 | 显示占用原因，禁用开始 |
| 定时场临近 | 服务端 `session_soon` 触发强开确认 |
| 运行已变化 | 不沿用旧 `run_id`，弹窗说明 |
| 字段缺失 | 单字段降级，不影响锁、最近一场、进度和紧急停止 |

## 5. 视觉与交互规范

- **颜色**：统一走 `Palette`，深浅色成对定义；七段各有固定颜色。
- **图形**：日常用七段图，活动用普通 / EX / S 三层圆环，抄作业运行用单环。
- **触控**：高频按钮不小于 44pt，主操作放在底部安全区上方。
- **字体**：默认字号按设计稿，跟随 Dynamic Type，最大到 AX2。
- **高危操作**：开跑、强开、开打、停止都用屏幕居中的系统确认弹窗。
- **反馈**：写操作成功用轻触觉，开跑和开打用成功触觉。
- **无障碍**：自绘图形提供 VoiceOver 文案，选中态使用 `.isSelected`。

## 7. 差异与待确认

### 已修复

| # | 原差异 | 现状 |
|---|---|---|
| D1 | 118 处固定字号，调大系统字体后大部分文字不变 | 默认字号不变，文字跟随系统字体，最大到 AX2；圆环内文字固定，运行胶囊最大到 xxxLarge |
| D2 | 开跑、强开、开打、停止用居中 `alert` | 曾改为 `confirmationDialog`，真机上是贴底气泡、没有显式取消且易误触，S3-5 后改回居中 `alert` |
| D3 | 连接详情只读，「重新配对」从空表单开始 | 连接详情可「编辑」，表单预填当前配置；扫到同一台 Mac 时保留凭据，地址或指纹变了不带旧凭据 |

### 建议接受

| # | 差异 | 原因 |
|---|---|---|
| A1 | E6 圆环显示「编队 12/12」，实现显示「练度 %」 | 后端不下发编队人数 |
| A2 | E27 左滑撤销，实现在已通格上用菜单撤销 | 已通关卡是网格，没有列表行可左滑 |
| A3 | Spec 用 emoji 区分关卡状态，实现用色点 + 文字 | 更易读，也符合去冗余原则 |
| A4 | 调度器、签名只读，高级为占位 | 属于 Phase 4 |
